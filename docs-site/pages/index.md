# CotaForge

Mechanical design in FreeCAD, with Claude Code.

[Install](install.md){ .md-button .md-button--primary }
[Your first design](first-part.md){ .md-button }

!!! warning "Early development version"
    Expect errors and changes. It works only with Claude Code and FreeCAD 1.1.

## What it does

Start from an idea. Depending on how much you want to work with it, the AI helps you build:

- a sketch;
- a partial design that you finish by hand;
- a final design.

It proposes solutions, above all when you are stuck. It searches for commercial components. The more context you give, the better its proposals.

If you already know which commercial parts you will use, download their 3D files and hand them over. The design then matches reality.

It also helps make the drawings. As with any AI work, review them before production.

You choose how to start: [three ways](how-it-works.md#three-ways-to-start). We recommend a sketch first.
