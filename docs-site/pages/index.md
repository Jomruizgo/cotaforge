# CotaForge

Mechanical design in FreeCAD, driven from Claude Code. You describe the part. CotaForge builds it in small steps, measures each one and makes the shop drawing.

[Install](install.md){ .md-button .md-button--primary }
[Your first part](first-part.md){ .md-button }

!!! warning "Alpha"
    It works only with Claude Code and FreeCAD 1.1.

## What it does

- **Models.** Every sketch is fully dimensioned. You can interrupt and undo any step.
- **Measures.** Volumes, sizes and hole lists come from FreeCAD, not from the model's guess.
- **Questions.** If a decision looks wrong, it says so and gives the reason. You decide.
- **Remembers.** A rule you teach it is saved only after you approve it.
- **Draws.** The sheet is reviewed by someone other than its author before the PDF is written.
